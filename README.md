- **[L1 Cache Controller](https://github.com/armaanmxt/L1-Cache-Controller-)** · A direct-mapped cache controller with tag checks and a state machine for refills.
- **[Synchronous FIFO](https://github.com/armaanmxt/parameterized-synchronous-fifo)** · A configurable FIFO written in SystemVerilog and verified with cocotb.
